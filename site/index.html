Local-first Linux dictation

A small spell for text.

Press a key, speak, let go. Cantrip turns speech into clean text at your cursor — offline by default, calm status capsule, paste-first delivery.

Local STT

Parakeet TDT 0.6B int8 on CPU. Short takes in a few hundred milliseconds. Speech stays on the machine.

Honest HUD

Warm Minimal capsule. Spinner when busy. Real chunk fill only when multi-chunk STT reports N/M. Success flash, not a novel.

Paste-first

Finished text lands via clipboard + Ctrl+V so paragraphs survive. Type mode still available for terminals.

Optional cleanup

OpenAI-compatible postproc for filler removal and punctuation. Skip short transcripts. One pass by default.

Quickstart

cargo build --release
./target/release/cantrip models pull
./target/release/cantrip config init
./target/release/cantrip daemon &
./target/release/cantrip toggle

Needs PipeWire, Wayland layer-shell, and wl-clipboard. See the full configuration guide.
